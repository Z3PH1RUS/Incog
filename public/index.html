Bring your own hostname

You cannot mint a brand-new .com for free. Every public URL is a name under someone’s domain. What you can do without buying anything is take a free subdomain so the address bar is not Railway, GitHub, or Vercel.

  1. Create a free Dynu account. Add DDNS: host incog, domain dynu.net → incog.dynu.net.
  2. Open that hostname → DNS Records. Delete the A and AAAA rows Dynu created.
  3. Add the CNAME and TXT below. Node name for CNAME is blank. Node name for TXT is _railway-verify.

incog.dynu.net is already attached on Railway. FreeDNS cannot do this — Dynu can. After the two records save, wait a minute and open https://incog.dynu.net.

CNAME qom0vyax.up.railway.app
TXT name _railway-verify
TXT value railway-verify=f8ea0d87f6ca3754935c77e9cc9bb801bf30bdd15e2cbc29f7495c7e544ce019

If Dynu refuses CNAME on the hostname itself, say so — we can switch the Railway name to www.incog.dynu.net.
